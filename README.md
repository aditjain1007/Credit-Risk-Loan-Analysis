# Credit Risk & Loan Analysis

## Project Overview

This project analyzes customer credit and loan data to understand the factors associated with **Good and Bad credit risk**.

The project was created as a portfolio data analytics project using **Python, Pandas, Statistics, and Data Visualization**. The analysis focuses on customer financial information, loan characteristics, and demographic factors to identify patterns that can support better credit-risk assessment.

The dataset used in this project is a **publicly available German Credit Risk dataset** hosted on GitHub and used for educational and analytical purposes.

---

## Business Problem

Financial institutions need to assess the credit risk of customers before approving loans.

The main business questions addressed in this project are:

- Which customer characteristics are associated with different credit-risk categories?
- Does loan amount differ between Good and Bad credit-risk customers?
- Does loan duration have a relationship with credit risk?
- How does customer age vary across risk categories?
- How do housing conditions relate to credit risk?
- Do saving and checking account statuses show different risk patterns?
- Does job category show differences in credit-risk distribution?
